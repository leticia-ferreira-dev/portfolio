## SelNet

Site fictício de um provedor de internet, com página inicial, planos, login e cadastro. Projeto **em grupo**.

**Minha parte:** cadastro, login e acessibilidade.

- **Cadastro:** máscaras de CPF, CEP e telefone; validação matemática do CPF; validação de nome e senha em tempo real; busca de endereço pelo CEP (API ViaCEP).
- **Login:** autenticação simulada com `localStorage`, com mensagens de retorno ao usuário.
- **Acessibilidade:** botões para aumentar e restaurar o tamanho do texto, modo de alto contraste e atributos ARIA no menu de acesso.

**Páginas:**
[Início](https://leticia-ferreira-dev.github.io/portfolio/selnet/telas/index.html) ·
[Planos móvel](https://leticia-ferreira-dev.github.io/portfolio/selnet/telas/planos_movel.html) ·
[Login](https://leticia-ferreira-dev.github.io/portfolio/selnet/login_cadastro/login/login.html) ·
[Cadastro](https://leticia-ferreira-dev.github.io/portfolio/selnet/login_cadastro/cadastro/cadastro.html)

> Os dados do site são fictícios. O cadastro é uma simulação feita só no navegador: não use senhas reais.

Ele precisa do Python rodando na máquina, por isso **não funciona no GitHub Pages**. As instruções de uso estão no [LEIA-ME](sistema_loja_escolar/LEIA-ME.txt). Todos os nomes e dados são fictícios.
