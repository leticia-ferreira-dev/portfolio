# Catálogo de Jogos (PS2)

Trabalho em grupo da faculdade: página que busca jogos de PS2 consumindo a **API da RAWG** (HTML, CSS e JavaScript).

## Sobre os dados exibidos
- **Versão online / sem chave:** roda em **modo demonstração**, com uma lista de exemplo (só nomes, sem capas e notas). Um aviso na tela deixa isso claro. Isso existe porque a chave da API é pessoal e não pode ficar pública no GitHub.
- **Com chave:** a página consome a RAWG de verdade (nomes, capas e notas reais). Para usar, copie `config.example.js` para `config.js`, cole sua chave gratuita (rawg.io/apidocs) e abra o `index.html`.
- O `config.js` está no `.gitignore` e nunca deve ser enviado ao GitHub.
